# Horizon AI Lab — Adaptive RAG Frontend

Adaptive RAG web UI built with Angular, featuring cyberpunk glassmorphism design and full visibility into routing + classifier decisions.

## Tech Stack

- **Angular 19**
- **TypeScript**
- **Cyberpunk glassmorphism UI**

## Prerequisites

- **Node.js 18+**
- **Angular CLI**

## Start Command

```bash
cd frontend
npx @angularAction: Run Background task in Blackbox CLI in the VS Code terminal (/cli <instruction>) (see below for action prompt) serve
```

Open:

- http://localhost:4200

## Features

- **Login/Register with JWT**
- **Query box** with **Ask AI** and **Probe Classifier** buttons
- **Live routing metadata panel** (intent, route, retrieval, confidence)
- **Classifier trace display**
- **Recent query history sidebar**

## Connected Backends

- **RAG backend:** http://localhost:8001
- **Classifier:** http://localhost:8000
